# 🌱 씨앗노트 (seednote-lite)

> 안드로이드 폰에서 목소리나 글로 생각을 남기면 내 컴퓨터 옵시디언에 바로 저장되는 앱

---

## 이런 분들께 딱 맞아요

- 걷다가, 운전하다가 떠오른 생각을 바로 남기고 싶은 분
- 옵시디언을 쓰는데 폰에서 빠르게 메모하고 싶은 분
- 코딩을 몰라도 직접 만들어 쓰고 싶은 분

---

## 작동 원리

```
📱 폰  →  🌐 와이파이  →  💻 내 컴퓨터  →  📓 옵시디언
말하거나 입력         서버가 받아서         자동 저장!
```

---

## 기능

- 🎤 **음성 입력** — 마이크 버튼 누르고 말하면 텍스트로 변환
- ⌨️ **텍스트 입력** — 직접 타이핑도 가능
- 📓 **옵시디언 자동 저장** — 저장 버튼 하나로 즉시 저장
- 🌐 **외부 접속** — Cloudflare Tunnel로 집 밖에서도 사용 가능
- 📱 **PWA** — 홈 화면에 추가하면 앱처럼 사용 가능
