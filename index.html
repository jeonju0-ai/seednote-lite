이 앱은 왜 만들어졌나요?

좋은 생각은 언제나 예고 없이 찾아옵니다.
걷다가, 운전하다가, 샤워하다가 — 그 순간 메모하지 않으면 사라져버려요.

기존 메모 앱들은 앱 안에 데이터가 갇혀 있어요. 나중에 찾기도 어렵고, 내가 쌓아온 지식과 연결되지 않아요.
씨앗노트는 달라요. 폰에서 남긴 생각이 곧바로 내 컴퓨터 옵시디언에 저장돼요.
내 지식 베이스에 바로 연결되는 거예요.

그리고 이 앱은 오픈소스예요.
코딩을 몰라도 이 가이드만 따라하면 누구나 직접 만들어 쓸 수 있어요.
나만의 씨앗노트를 직접 만든다는 것, 그 자체도 하나의 배움이 될 수 있어요.

🌱

씨앗(아이디어)을 심으면 — 언젠가 큰 나무가 된다는 의미를 담았어요.

🔓

🆓

3
Node.js 설치하기
▼

Node.js는 서버 프로그램을 실행하기 위해 필요한 무료 도구예요. 한 번만 설치하면 됩니다.

설치 방법

  1. nodejs.org 에 접속합니다
  2. LTS 버전 (왼쪽 초록 버튼) 을 클릭해서 설치 파일을 다운받습니다
  3. 다운받은 파일을 더블클릭해서 설치합니다 (계속 "다음" 클릭)
  4. 설치 완료 후 컴퓨터를 재시작하면 준비 끝!
이미 Node.js가 설치되어 있다면 이 단계를 건너뛰세요. 확인 방법: 터미널에 node -v 를 입력해서 버전 번호가 나오면 됩니다.
4
서버 실행하기
▼

내 컴퓨터에서 서버를 실행하는 단계예요. 폰에서 보낸 내용을 받아서 옵시디언에 저장하는 역할을 합니다.

① 터미널 열기

  1. 키보드에서 Command(⌘) + 스페이스바 를 동시에 누릅니다
  2. 검색창에 터미널 을 입력합니다
  3. 터미널 앱이 나오면 엔터를 누릅니다
  4. 검은 창이 뜨면 성공!
⬛이런 검은 창이 뜨면 터미널이 열린 거예요

② 다운받은 폴더로 이동하기

바탕화면에 저장한 경우 아래 명령어를 복사해서 터미널에 붙여넣으세요.

cd ~/Desktop/seednote-lite-main/server
터미널에 붙여넣는 법
복사 버튼을 누른 뒤 터미널 창을 클릭하고
키보드에서 Command(⌘) + V 를 누르면 붙여넣기가 됩니다.
그 다음 엔터 를 누르면 실행돼요.

③ 필요한 도구 설치 (최초 1회)

npm install

완료되면 이런 문구가 나와요: added XX packages

④ 서버 실행하기

node server.js
성공하면 이런 문구가 나와요:
씨앗노트 서버 실행 중
http://localhost:3456
저장 경로: /Users/.../Obsidian Vault/0.Inbox
이 창을 닫지 마세요! 서버가 꺼지면 폰에서 저장이 안 돼요.
폰으로 메모할 때는 항상 이 창이 열려 있어야 합니다.
컴퓨터를 껐다 켰다면?
터미널을 다시 열고 아래 명령어를 실행하면 돼요: 
cd ~/Desktop/seednote-lite-main/server && node server.js

① 명령 프롬프트 열기

  1. 키보드에서 Windows 키 + R 을 동시에 누릅니다
  2. 작은 창이 뜨면 cmd 를 입력하고 엔터를 누릅니다
  3. 검은 창이 뜨면 성공!
⬛이런 검은 창이 뜨면 명령 프롬프트가 열린 거예요

내 컴퓨터 IP 주소 찾기
▼

IP 주소는 내 컴퓨터의 집 주소 같은 거예요. 폰이 컴퓨터를 찾아오려면 이 주소가 필요합니다.

Mac에서 IP 주소 찾기

방법 1 — 터미널 명령어 (빠름)

ipconfig getifaddr en0

결과 예시: 192.168.0.15 — 이게 내 IP 주소예요!

방법 2 — 화면으로 찾기

  1. 화면 왼쪽 위 🍎 Apple 메뉴 클릭
  2. 시스템 설정 클릭
  3. 왼쪽에서 Wi-Fi 클릭
  4. 연결된 와이파이 옆 세부사항 클릭
  5. IP 주소 항목의 숫자를 메모하세요

Windows에서 IP 주소 찾기

방법 1 — 명령어 (빠름)

ipconfig

무선 LAN 어댑터 Wi-Fi 항목에서
IPv4 주소 옆의 숫자를 메모하세요. 예: 192.168.0.15

방법 2 — 화면으로 찾기

  1. 화면 오른쪽 아래 Wi-Fi 아이콘을 클릭
  2. 연결된 와이파이 옆 속성 클릭
  3. 아래로 스크롤해서 IPv4 주소 확인
IP 주소 예시: 192.168.0.15, 192.168.1.100, 10.0.0.5
앞에 192.168. 또는 10.0. 으로 시작하는 숫자예요.
이걸 메모해두세요 — 다음 단계에서 씁니다!

8
집 밖에서도 쓰기 — Cloudflare Tunnel (선택)
▼

지금까지 설정한 방법은 같은 와이파이에 있을 때만 작동해요.
밖에서도 쓰고 싶다면 Cloudflare Tunnel을 쓰면 됩니다.

Cloudflare Tunnel이란?
내 컴퓨터에 안전한 인터넷 통로를 만들어주는 도구예요.
설치하면 어디서든 내 컴퓨터 서버에 접근할 수 있어요. 무료!

Mac에서 설치하기

터미널을 열고 아래 명령어를 순서대로 실행하세요.

brew install cloudflare/cloudflare/cloudflared
brew가 없다면 먼저 이걸 실행하세요: 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Windows에서 설치하기

  1. Cloudflare 다운로드 페이지 접속
  2. Windows 64-bit 설치 파일 다운로드 및 설치

터널 실행하기

서버를 먼저 켜둔 상태에서, 새 터미널 창을 열고 실행:

cloudflared tunnel --url http://localhost:3456
잠시 후 이런 주소가 나와요:
https://xxxx-xxxx.trycloudflare.com

이 주소를 앱 설정의 서버 주소에 입력하면
어디서든 저장할 수 있어요!
Cloudflare Tunnel 주소는 매번 바뀌어요.
쓸 때마다 새 주소를 앱 설정에 입력해야 합니다.

📤 폰으로 주소 전송하기

카카오톡 나에게 보내기로 아래 두 주소를 보내세요.
서버 주소는 8단계(Cloudflare)에서 만든 주소를 붙여넣으면 돼요.

① 앱 주소 — 폰 크롬에서 여는 주소

https://jeonju0-ai.github.io/seednote-lite/app/

② 서버 주소 — 앱 설정 ⚙️에 입력할 주소

8단계 Cloudflare 주소를 아래에 붙여넣으세요 (매번 바뀌어요)

https://xxxx.trycloudflare.com

복사 후 카카오톡 나에게 보내기에 붙여넣기(길게 누르기)하면 돼요

자주 묻는 질문

저장이 안 돼요 / 연결 실패가 나와요

1. 컴퓨터에서 서버가 실행 중인지 확인하세요 (터미널 창이 열려 있어야 해요)
2. 폰과 컴퓨터가 같은 와이파이에 연결되어 있는지 확인하세요
3. IP 주소가 맞는지 확인하세요 (컴퓨터를 재시작하면 IP가 바뀔 수 있어요)
4. Mac이라면 시스템 설정 → 방화벽에서 Node.js를 허용해주세요

컴퓨터를 껐다 켜면 다시 설정해야 하나요?

서버는 다시 실행해야 해요. 4단계 맨 아래에 재실행 명령어가 있어요.
앱 설정(서버 주소)은 저장되어 있어서 다시 입력하지 않아도 됩니다.

옵시디언 어디에 저장되나요?

기본적으로 옵시디언 볼트의 0.Inbox 폴더에 저장됩니다.
파일 이름 예시: 씨앗_2026-06-05_21-30.md

아이폰이나 다른 기기에서도 쓸 수 있나요?

네! 크롬 브라우저가 있는 기기라면 어디서든 쓸 수 있어요.
단, 음성 입력은 크롬에서 가장 잘 됩니다.
사파리(아이폰)에서는 음성 입력이 제한될 수 있어요.

여러 명이 같이 쓸 수 있나요?

같은 서버 주소를 공유하면 여러 명이 같은 옵시디언에 저장할 수 있어요.
각자 본인 옵시디언에 저장하고 싶다면 각자 서버를 실행해야 합니다.
